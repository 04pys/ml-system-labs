# Overfitting을 막는 방법 복습 트리거

## 1. Overfitting이란?

Overfitting은 모델이 훈련 데이터에는 너무 잘 맞지만, 새로운 데이터에는 잘 동작하지 않는 상태이다.

즉, 모델이 일반적인 규칙을 배운 것이 아니라 훈련 데이터의 세부 패턴이나 노이즈까지 외운 상태이다.

예시:

훈련 정확도: 98%
검증 정확도: 75%

이 경우 모델은 훈련 데이터에는 잘 맞지만, 새로운 데이터에 일반화하지 못하고 있을 가능성이 높다.

---

## 2. 과적합을 막는 대표적인 방법

### 1) 데이터의 양 늘리기

데이터가 적으면 모델이 특정 샘플의 우연한 패턴까지 외우기 쉽다.

데이터가 많아지면 모델은 개별 샘플의 특이한 패턴보다 전체 데이터에 공통적으로 나타나는 일반적인 패턴을 학습하기 쉽다.

이미지 데이터에서는 기존 이미지를 조금 변형해 데이터를 늘리는 데이터 증강을 자주 사용한다.

예시:

- 이미지를 살짝 회전
- 이미지를 좌우 반전
- 일부 영역을 자르기
- 노이즈 추가
- 밝기 변화

핵심:

데이터가 부족하면 외우기 쉬움
데이터가 많으면 일반적인 규칙을 배우기 쉬움

---

### 2) 모델의 복잡도 줄이기

모델이 너무 복잡하면 훈련 데이터의 세세한 패턴까지 표현할 수 있다.

인공 신경망에서 모델의 복잡도는 주로 다음과 관련된다.

- 은닉층의 수
- 뉴런의 수
- 전체 파라미터 수

파라미터가 많을수록 모델의 capacity, 즉 표현력이 커진다.

표현력이 큰 모델은 어려운 패턴도 학습할 수 있지만, 데이터가 충분하지 않으면 노이즈까지 외울 위험이 커진다.

예시:

과적합된 모델:
입력층 → 은닉층1 → 은닉층2 → 출력층

복잡도 줄인 모델:
입력층 → 은닉층1 → 출력층

핵심:

모델이 너무 똑똑해서 훈련 데이터를 외우는 상황이라면, 모델을 조금 단순하게 만드는 것이 도움이 될 수 있다.

---

## 3. L1, L2 규제

규제는 모델이 훈련 데이터에 너무 억지로 맞춰지는 것을 막기 위해 손실 함수에 추가적인 벌점을 주는 방법이다.

원래 목표:

예측 오차를 줄이자

규제 추가 후:

예측 오차도 줄이되, 가중치가 너무 커지지는 않게 하자

즉, 모델에게 다음과 같이 제한을 거는 것이다.

훈련 데이터에 잘 맞추는 것은 좋지만, 너무 복잡한 방식으로 맞추지는 마라.

---

## 4. L1 규제

L1 규제는 가중치의 절댓값 합을 손실 함수에 더한다.

plain text 수식:

Loss_total = Loss_data + lambda * sum(|w|)

여기서 lambda는 규제 강도를 의미한다.

lambda가 크면 가중치를 작게 만들라는 압력이 강해진다.

L1 규제의 특징은 일부 가중치를 정확히 0으로 만들기 쉽다는 점이다.

예시:

H(x) = w1*x1 + w2*x2 + w3*x3 + w4*x4

L1 규제를 적용한 뒤:

w1 = 1.2
w2 = 0.8
w3 = 0
w4 = 0

이 경우 x3, x4는 사실상 모델에서 사용되지 않는다.

따라서 L1 규제는 의미 없는 특성을 제거하는 feature selection 효과를 가질 수 있다.

---

## 5. L2 규제

L2 규제는 가중치의 제곱합을 손실 함수에 더한다.

plain text 수식:

Loss_total = Loss_data + lambda * sum(w^2)

L2 규제는 큰 가중치를 강하게 억제한다.

예시:

w = 10이면 w^2 = 100
w = 2이면 w^2 = 4
w = 0.1이면 w^2 = 0.01

큰 가중치일수록 제곱값이 커지므로, 모델은 특정 특성 하나에 너무 큰 가중치를 주는 것을 피하게 된다.

하지만 L2는 보통 가중치를 정확히 0으로 만들지는 않는다.

그 이유는 미분했을 때의 형태 때문이다.

L2 규제항:

lambda * w^2

미분:

2 * lambda * w

즉, w가 클 때는 규제의 힘이 크지만, w가 0에 가까워질수록 규제의 힘도 작아진다.

예시:

w = 10이면 크게 줄임
w = 1이면 조금 줄임
w = 0.01이면 거의 안 줄임

그래서 L2는 가중치를 전체적으로 작게 만들지만, 작은 가중치를 완전히 0으로 제거하는 효과는 약하다.

---

## 6. L1과 L2의 핵심 차이

L1:

Loss_total = Loss_data + lambda * sum(|w|)

미분 직관:

w가 0이 아닌 한, 0 방향으로 일정한 힘을 계속 준다.

그래서 작은 가중치도 끝까지 밀어서 0으로 만들기 쉽다.

L2:

Loss_total = Loss_data + lambda * sum(w^2)

미분 직관:

2 * lambda * w

w가 작아질수록 규제의 힘도 작아진다.

그래서 가중치를 작게 만들지만, 정확히 0으로 만들기는 어렵다.

정리:

L1 = 쓸모없는 특성을 0으로 만들어 버리는 경향
L2 = 큰 가중치를 부드럽게 눌러 안정화하는 경향

---

## 7. L1, L2는 언제 사용할까?

과적합이 나타날 때 사용한다.

예시:

훈련 데이터 정확도는 높은데 검증 데이터 정확도가 낮은 경우

훈련 정확도: 98%
검증 정확도: 75%

이런 경우 모델이 훈련 데이터의 우연한 패턴까지 외웠을 가능성이 있다.

예를 들어 합격 예측 모델에서 특성이 다음과 같다고 하자.

- 공부 시간
- 기출 풀이 개수
- 수면 시간
- 수험번호 끝자리
- 필통 색깔

실제로 중요한 것은 공부 시간, 기출 풀이 개수, 수면 시간일 가능성이 높다.

그런데 훈련 데이터에서 우연히 수험번호 끝자리가 7인 사람이 많이 합격했다면, 모델은 수험번호 끝자리에 큰 가중치를 줄 수 있다.

규제 전:

공부 시간: 1.2
기출 풀이 개수: 1.5
수면 시간: 0.8
수험번호 끝자리: 5.7
필통 색깔: -3.2

이 경우 모델은 의미 없는 특성에 과하게 의존하고 있다.

L2 적용 후:

공부 시간: 0.9
기출 풀이 개수: 1.1
수면 시간: 0.6
수험번호 끝자리: 1.0
필통 색깔: -0.4

L2는 이상하게 큰 가중치를 줄여 모델이 특정 특성에 과도하게 의존하지 않게 만든다.

L1 적용 후:

공부 시간: 1.0
기출 풀이 개수: 1.2
수면 시간: 0.5
수험번호 끝자리: 0
필통 색깔: 0

L1은 의미 없는 특성의 가중치를 0으로 만들어 사실상 제거할 수 있다.

---

## 8. L1 사용 시 주의점

L1은 의미 없는 특성을 제거하는 데 유용하지만, 규제 강도가 너무 크면 의미 있는 특성까지 제거할 수 있다.

예시:

실제로 중요한 특성:

- 공부 시간
- 기출 풀이 개수
- 수면 시간

그런데 L1 규제가 너무 강하면:

공부 시간: 0
기출 풀이 개수: 1.2
수면 시간: 0
수험번호 끝자리: 0
필통 색깔: 0

이렇게 중요한 특성까지 0이 될 수 있다.

특히 공부 시간과 기출 풀이 개수처럼 서로 비슷한 정보를 주는 특성이 있으면, L1은 둘 중 하나만 남기고 다른 하나를 0으로 만들 수도 있다.

이때 0이 되었다고 해서 반드시 그 특성이 현실적으로 의미 없다는 뜻은 아니다.

모델 입장에서 다른 특성으로 비슷한 정보를 설명할 수 있었기 때문에 제거했을 수도 있다.

---

## 9. 파이토치에서 L2 규제 사용하기

파이토치에서는 optimizer의 weight_decay 값을 설정하면 L2 규제를 적용할 수 있다.

예시:

optimizer = torch.optim.Adam(model.parameters(), lr=1e-4, weight_decay=1e-5)

여기서 weight_decay가 L2 규제 강도에 해당한다.

weight_decay의 기본값은 0이다.

즉, 따로 설정하지 않으면 L2 규제가 적용되지 않는다.

## 10. 드롭아웃

드롭아웃은 학습 과정에서 신경망의 일부 뉴런을 랜덤하게 사용하지 않는 방법이다.

예를 들어 dropout 비율이 0.5라면, 학습할 때마다 절반 정도의 뉴런을 랜덤하게 꺼버린다.

핵심 효과:

모델이 특정 뉴런이나 특정 뉴런 조합에 과하게 의존하지 못하게 한다.

매번 다른 일부 뉴런만 사용하므로, 여러 모델을 함께 학습시키는 앙상블과 비슷한 효과를 낸다.

주의점:

드롭아웃은 학습 시에만 사용하고, 예측 시에는 사용하지 않는 것이 일반적이다.

학습 시:

일부 뉴런을 랜덤하게 끔

예측 시:

전체 뉴런을 사용함

---

## 11. 전체 정리

과적합이란:

훈련 데이터의 일반적인 규칙이 아니라, 훈련 데이터의 노이즈와 우연한 패턴까지 외운 상태

과적합을 막는 방법:

1. 데이터 양 늘리기
   - 데이터가 많을수록 일반적인 패턴을 학습하기 쉬움

2. 데이터 증강
   - 기존 데이터를 변형해 학습 데이터를 늘림

3. 모델 복잡도 줄이기
   - 은닉층 수, 뉴런 수, 파라미터 수를 줄임

4. L1 규제
   - 가중치 절댓값 합을 손실에 추가
   - 일부 가중치를 0으로 만들기 쉬움
   - 특성 선택 효과 있음

5. L2 규제
   - 가중치 제곱합을 손실에 추가
   - 큰 가중치를 강하게 억제
   - 가중치를 작게 만들지만 0으로 만들지는 않는 경향
   - 딥러닝에서는 weight decay로 자주 사용

6. 드롭아웃
   - 학습 중 일부 뉴런을 랜덤하게 끔
   - 특정 뉴런 조합에 과도하게 의존하는 것을 방지

---

## 12. 한 줄 복습

Overfitting을 막는 핵심은 모델이 훈련 데이터를 외우지 못하게 하고, 새로운 데이터에도 통하는 일반적인 패턴을 배우도록 제한하는 것이다.

L1은 필요 없는 특성을 0으로 만들어 제거하는 방향이고, L2는 큰 가중치를 부드럽게 눌러 특정 특성에 과하게 의존하지 않도록 만드는 방향이다.
