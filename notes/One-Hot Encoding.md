# One-Hot Encoding

## 1. One-Hot Encoding이란

범주형 데이터를  
**해당 위치만 1, 나머지는 0**으로 표현하는 방법이다.

예시:

- 강아지 = `[1, 0, 0]`
- 고양이 = `[0, 1, 0]`
- 사과 = `[0, 0, 1]`

---

## 2. 왜 쓰는가

클래스를 그냥 숫자로 두면  
모델이 **크기나 순서가 있다고 오해할 수 있기 때문**이다.

예:

- 바나나 = 1
- 토마토 = 2
- 사과 = 3

이렇게 두면  
모델은 바나나와 토마토가  
바나나와 사과보다 더 가깝다고 받아들일 수 있다.

하지만 일반적인 분류 문제에서는  
이런 순서가 없는 경우가 많다.

---

## 3. 핵심 장점

One-Hot Encoding은  
**클래스들 사이에 쓸데없는 순서 정보가 없다.**

즉,

- A가 B보다 C에 더 가깝다
- 어떤 클래스가 더 크다

이런 잘못된 해석을 줄일 수 있다.

---

## 4. 유클리드 거리와 One-Hot

유클리드 거리는  
**두 점 사이의 직선 거리**이다.

간단한 정의:

`distance(a, b) = sqrt(각 좌표 차이의 제곱의 합)`

One-Hot 벡터는  
서로 다른 두 클래스 사이의 거리가 항상 같다.

즉,

- `[1, 0, 0]` 와 `[0, 1, 0]`
- `[1, 0, 0]` 와 `[0, 0, 1]`

의 거리가 동일하다.

### 기억할 말
**One-Hot은 모든 클래스가 서로 똑같이 떨어져 있게 만든다.**

---

## 5. 단점

One-Hot은  
클래스 사이의 **유사성 정보**는 담지 못한다.

즉,

- 사과
- 배
- 포도

가 실제로 비슷해도  
One-Hot에서는 그냥 전부 똑같이 떨어진 별개 클래스일 뿐이다.

---

## 6. 정수 인코딩이 더 나은 경우

**클래스에 순서가 있을 때**는  
정수 인코딩이 더 자연스러울 수 있다.

예:

- 아기 / 어린이 / 청소년 / 성인
- 1층 / 2층 / 3층 / 4층
- 10대 / 20대 / 30대 / 40대

이런 경우는  
앞뒤 순서, 크기, 단계 정보가 중요하므로  
정수 인코딩이 더 잘 맞을 수 있다.

---

## 7. 언제 뭘 쓰는가

### 순서가 없는 class
- One-Hot Encoding이 보통 적절함

### 순서가 있는 class
- 정수 인코딩이 더 자연스러울 수 있음

---

## 8. 최종 한 줄 요약

One-Hot Encoding은  
**순서가 없는 범주형 데이터를 공평하게 표현하기 위한 방법**이다.
