# Gradient Vanishing / Exploding 복습 트리거

## 1. 기울기 소실과 기울기 폭주

딥러닝에서는 역전파를 통해 출력층에서 입력층 방향으로 gradient가 전달된다.

그런데 신경망이 깊어질수록 gradient가 여러 층을 거치며 계속 곱해진다.

이때 gradient가 점점 작아지면 기울기 소실이 되고, gradient가 점점 커지면 기울기 폭주가 된다.

기울기 소실:

- 입력층에 가까운 층으로 갈수록 gradient가 거의 0에 가까워짐
- 앞쪽 층의 가중치가 거의 업데이트되지 않음
- 깊은 신경망이 제대로 학습되지 않음

기울기 폭주:

- 역전파 과정에서 gradient가 비정상적으로 커짐
- 가중치가 너무 크게 업데이트됨
- 손실이 발산하거나 NaN이 발생할 수 있음
- RNN 계열에서 특히 자주 문제됨

핵심:

gradient는 역전파 과정에서 여러 미분값이 곱해지므로,
작은 값들이 반복해서 곱해지면 소실되고,
큰 값들이 반복해서 곱해지면 폭주한다.

---

## 2. sigmoid와 기울기 소실

sigmoid 함수는 출력이 0과 1 사이이다.

문제는 입력값의 절댓값이 클 때 발생한다.

입력이 매우 크면 sigmoid 출력은 1에 가까워지고,
입력이 매우 작으면 sigmoid 출력은 0에 가까워진다.

이 구간에서는 그래프가 거의 평평해진다.

그래프가 평평하다는 것은 미분값이 작다는 뜻이다.

즉:

sigmoid 입력값이 너무 큼 또는 작음
→ sigmoid 출력이 0 또는 1 근처로 포화됨
→ 미분값이 거의 0이 됨
→ 역전파되는 gradient가 작아짐
→ 앞쪽 층으로 갈수록 기울기 소실 발생

그래서 은닉층에서는 sigmoid를 잘 사용하지 않는다.

---

## 3. ReLU와 Leaky ReLU

기울기 소실을 줄이기 위해 은닉층에서는 sigmoid나 tanh보다 ReLU 계열을 자주 사용한다.

ReLU:

ReLU(x) = max(0, x)

특징:

- x > 0이면 기울기가 1
- 양수 구간에서는 gradient가 잘 전달됨
- sigmoid처럼 양수 입력에서 포화되지 않음

하지만 ReLU에도 문제가 있다.

x <= 0이면 출력이 0이고, 기울기도 0이다.

어떤 뉴런이 계속 음수 입력만 받으면 gradient가 흐르지 않아 더 이상 학습되지 않을 수 있다.

이를 죽은 ReLU 문제라고 한다.

Leaky ReLU:

- 음수 구간에서도 아주 작은 기울기를 남겨둠
- 음수 입력에서도 gradient가 완전히 0이 되지 않음
- 죽은 ReLU 문제를 완화함

핵심:

sigmoid:
입력이 커지거나 작아지면 기울기가 0에 가까워짐

ReLU:
양수 구간에서는 기울기 전달이 잘 됨

Leaky ReLU:
음수 구간에서도 약간의 기울기를 남겨 죽은 ReLU를 완화함

## 4. 가중치 초기화가 중요한 이유

신경망의 각 층은 대략 다음 계산을 반복한다.

z = w1*x1 + w2*x2 + ... + wn*xn
a = activation(z)

초기 가중치가 너무 작으면 층을 지날수록 값과 gradient가 작아질 수 있다.

초기 가중치가 너무 크면 층을 지날수록 값과 gradient가 커질 수 있다.

따라서 초기화의 핵심 목표는 다음과 같다.

앞 층에서 들어온 신호의 크기를 다음 층에서도 적당히 유지하자.

즉, forward 방향의 activation도 너무 작거나 커지지 않게 하고,
backward 방향의 gradient도 너무 작거나 커지지 않게 하는 것이 중요하다.

## 5. Xavier 초기화

Xavier 초기화는 Glorot 초기화라고도 한다.

주로 sigmoid, tanh, linear 계열 activation과 잘 맞는다.

Xavier 초기화는 이전 층의 뉴런 수 fan_in과 다음 층의 뉴런 수 fan_out을 함께 고려한다.

### Xavier Uniform

가중치를 균등분포에서 뽑는다.

plain text 수식:

W ~ Uniform(-sqrt(6 / (fan_in + fan_out)), +sqrt(6 / (fan_in + fan_out)))

의미:

- -limit부터 +limit 사이에서 랜덤하게 가중치를 뽑음
- limit = sqrt(6 / (fan_in + fan_out))

### Xavier Normal

가중치를 정규분포에서 뽑는다.

plain text 수식:

W ~ Normal(mean = 0, std = sqrt(2 / (fan_in + fan_out)))

의미:

- 평균 0인 정규분포에서 각 가중치를 랜덤하게 뽑음
- 표준편차는 각 층의 fan_in, fan_out에 따라 결정됨

예시:

fan_in = 100
fan_out = 50

std = sqrt(2 / 150)
std ≈ 0.115

이 경우 각 가중치는 평균 0, 표준편차 0.115인 정규분포에서 뽑힌다.

예상되는 가중치 예시:

w1 = 0.034
w2 = -0.087
w3 = 0.142
w4 = -0.011
w5 = 0.221

여기서 중요한 점:

가중치가 모두 0.115가 되는 것이 아니다.
0.115는 랜덤값들이 0 주변에 얼마나 퍼질지를 정하는 표준편차이다.

---

## 6. He 초기화

He 초기화는 Kaiming 초기화라고도 한다.

주로 ReLU, Leaky ReLU, PReLU 같은 ReLU 계열 activation과 잘 맞는다.

ReLU는 음수 입력을 0으로 만든다.

즉, 입력이 0을 중심으로 대칭적으로 들어오면 대략 절반 정도의 신호가 죽는다.

그래서 ReLU 계열에서는 Xavier보다 조금 더 큰 분산으로 초기화하는 He 초기화가 적합하다.

### He Uniform

plain text 수식:

W ~ Uniform(-sqrt(6 / fan_in), +sqrt(6 / fan_in))

### He Normal

plain text 수식:

W ~ Normal(mean = 0, std = sqrt(2 / fan_in))

Xavier와의 차이:

Xavier:
fan_in과 fan_out을 모두 고려

He:
주로 fan_in을 기준으로 함

직관:

Xavier:
forward와 backward의 신호 균형을 맞추려는 초기화

He:
ReLU가 음수 신호를 죽이는 효과를 고려해, 처음부터 조금 더 큰 분산을 주는 초기화

---

## 7. Xavier vs He 정리

Xavier 초기화:

- sigmoid, tanh, linear 계열에 적합
- fan_in과 fan_out을 모두 고려
- Uniform: -sqrt(6 / (fan_in + fan_out)) ~ +sqrt(6 / (fan_in + fan_out))
- Normal: mean = 0, std = sqrt(2 / (fan_in + fan_out))

He 초기화:

- ReLU 계열에 적합
- 주로 fan_in을 고려
- Uniform: -sqrt(6 / fan_in) ~ +sqrt(6 / fan_in)
- Normal: mean = 0, std = sqrt(2 / fan_in)

실전 감각:

은닉층 activation이 tanh이면 Xavier를 우선 고려한다.
은닉층 activation이 ReLU이면 He를 우선 고려한다.
현대 딥러닝에서는 ReLU + He 초기화 조합이 자주 사용된다.

## 8. 내부 공변량 변화

내부 공변량 변화는 학습 중에 각 층이 받는 입력 분포가 계속 바뀌는 현상을 말한다.

여기서 입력 분포가 바뀐다는 말은 원본 데이터 x의 분포가 바뀐다는 뜻이 아니다.

각 층은 이전 층의 출력을 입력으로 받는다.

예를 들어:

입력 x → 1층 → 2층 → 3층 → 출력

2층의 입력은 원본 x가 아니라 1층의 출력이다.

그런데 학습 중에는 1층의 가중치가 계속 바뀐다.

그러면 같은 원본 데이터가 들어와도 1층의 출력이 계속 달라진다.

결과:

1층 가중치가 업데이트됨
→ 1층 출력 분포가 바뀜
→ 2층이 받는 입력 분포가 바뀜
→ 2층은 계속 변하는 입력에 적응해야 함

이것이 내부 공변량 변화이다.

핵심:

내부 공변량 변화란,
학습 중 앞쪽 층이 바뀌면서 뒤쪽 층이 받는 중간 표현값의 평균, 분산, 범위 등이 계속 변하는 현상이다.

## 9. 배치 정규화

배치 정규화는 각 층에 들어가는 값을 미니배치 단위로 정규화하는 방법이다.

목표:

각 층의 입력값이 너무 커지거나 작아지지 않게 해서 학습을 안정화한다.

문서 기준으로 배치 정규화는 보통 활성화 함수를 통과하기 전에 수행한다고 설명한다.

과정:

1. 미니배치의 평균을 구함
2. 미니배치의 분산을 구함
3. 평균을 빼고 표준편차로 나누어 x_hat을 구함
4. gamma와 beta로 다시 스케일 조정과 이동을 수행함

plain text 수식:

mu_B = (1/m) * sum(x_i)

var_B = (1/m) * sum((x_i - mu_B)^2)

x_hat_i = (x_i - mu_B) / sqrt(var_B + epsilon)

y_i = gamma * x_hat_i + beta

각 기호의 의미:

m:
미니배치 안의 샘플 수

mu_B:
미니배치 평균

var_B:
미니배치 분산

epsilon:
분모가 0이 되는 것을 막기 위한 작은 값

x_hat:
정규화된 값

gamma:
스케일을 조정하는 학습 파라미터

beta:
위치를 이동시키는 학습 파라미터

---

## 10. x_hat의 의미

x_hat은 단순히 값을 작게 만드는 것이 아니다.

x_hat은 다음 의미를 가진다.

이 값이 미니배치 평균으로부터 표준편차 몇 개만큼 떨어져 있는가?

예시:

미니배치 값:

x = [2, 4, 6, 8]

평균:

mu_B = 5

분산:

var_B = 5

표준편차:

std_B = sqrt(5) ≈ 2.236

정규화:

x_hat_1 = (2 - 5) / sqrt(5) ≈ -1.34
x_hat_2 = (4 - 5) / sqrt(5) ≈ -0.45
x_hat_3 = (6 - 5) / sqrt(5) ≈ 0.45
x_hat_4 = (8 - 5) / sqrt(5) ≈ 1.34

따라서:

x_hat ≈ [-1.34, -0.45, 0.45, 1.34]

직관:

2는 평균보다 약 1.34 표준편차 아래에 있는 값이다.
8은 평균보다 약 1.34 표준편차 위에 있는 값이다.

즉, x_hat은 값을 평균 0, 분산 1에 가까운 형태로 바꾼 것이다.

---

## 11. gamma와 beta가 필요한 이유

정규화만 하면 모든 값이 강제로 평균 0, 분산 1 근처로 맞춰진다.

하지만 어떤 층에서는 평균이 0이 아닌 값이나, 분산이 1보다 큰 값이 더 유리할 수도 있다.

그래서 배치 정규화는 정규화 후에 다시 다음 변환을 한다.

plain text 수식:

y = gamma * x_hat + beta

gamma:
값의 크기를 다시 조정

beta:
값의 위치를 다시 이동

핵심:

일단 x_hat으로 안정적인 표준 형태를 만들고,
필요하면 모델이 gamma와 beta를 학습해서 다시 적절한 분포로 바꿀 수 있게 한다.

---

## 12. 배치 정규화의 장점

배치 정규화를 사용하면 다음 효과가 있다.

1. 기울기 소실과 폭주를 완화할 수 있음
2. 가중치 초기화에 덜 민감해짐
3. 더 큰 학습률을 사용할 수 있어 학습이 빨라질 수 있음
4. 미니배치마다 평균과 분산이 달라져 약간의 잡음이 들어가는 효과가 있음
5. 이 잡음 효과가 과적합 완화에 일부 도움을 줄 수 있음

다만 과적합 방지가 주목적은 아니므로, 필요하면 Dropout 등과 함께 고려한다.

---

## 13. 배치 정규화의 학습 시점과 추론 시점 차이

학습 중에는 미니배치마다 평균과 분산을 계산한다.

하지만 추론할 때는 보통 미니배치 통계를 직접 쓰지 않는다.

학습 중 저장해둔 running mean과 running variance를 사용한다.

이유:

추론 시에는 입력 샘플이 1개일 수도 있고, 배치 구성이 학습 때와 다를 수 있다.
그때마다 배치 평균과 분산을 계산하면 결과가 불안정해질 수 있다.

정리:

train mode:
현재 미니배치의 평균과 분산 사용
running mean, running variance 업데이트

eval mode:
학습 중 누적한 running mean, running variance 사용

---

## 14. 배치 정규화의 한계

배치 정규화는 미니배치 크기에 의존한다.

배치 크기가 너무 작으면 평균과 분산 추정이 불안정하다.

특히 batch size = 1이면 분산 계산이 의미 없어질 수 있다.

또한 RNN에는 적용하기 어렵다.

RNN은 시점마다 입력의 성격이 달라질 수 있고, 각 time step마다 다른 통계를 가질 수 있다.

그래서 RNN이나 Transformer 계열에서는 LayerNorm이 더 자주 사용된다.

---

## 15. 층 정규화

층 정규화는 BatchNorm과 목적은 비슷하다.

목표:

각 층의 값이 너무 커지거나 작아지지 않게 해서 학습을 안정화한다.

하지만 평균과 분산을 구하는 기준이 다르다.

BatchNorm:

같은 특성에 대해 미니배치 안의 여러 샘플 값을 모아 평균과 분산을 구한다.

LayerNorm:

한 샘플 안의 여러 특성 값을 모아 평균과 분산을 구한다.

---

## 16. BatchNorm vs LayerNorm 예시

조건:

전체 샘플 수 = 12개
특성 수 = 5개
미니배치 크기 = 4개

그러면 전체 데이터는 미니배치 3개로 나뉜다.

미니배치 1: 샘플 1~4
미니배치 2: 샘플 5~8
미니배치 3: 샘플 9~12

각 미니배치의 모양:

X shape = 4 x 5

행:
샘플 4개

열:
특성 5개

### BatchNorm

BatchNorm은 열 방향으로 정규화한다.

즉, 같은 특성끼리 미니배치 안의 4개 샘플을 모아 평균과 분산을 구한다.

특성 1:

[x_11, x_21, x_31, x_41]

특성 2:

[x_12, x_22, x_32, x_42]

특성 5:

[x_15, x_25, x_35, x_45]

따라서 미니배치 하나에서 평균 5개, 분산 5개가 계산된다.

이유:

특성이 5개이므로, 각 특성마다 평균과 분산을 구하기 때문이다.

BatchNorm 직관:

이번 미니배치 안에서 각 특성이 평균적으로 어떻게 분포하는가?

### LayerNorm

LayerNorm은 행 방향으로 정규화한다.

즉, 샘플 하나 안의 5개 특성을 모아 평균과 분산을 구한다.

샘플 1:

[x_11, x_12, x_13, x_14, x_15]

샘플 2:

[x_21, x_22, x_23, x_24, x_25]

샘플 4:

[x_41, x_42, x_43, x_44, x_45]

따라서 미니배치 하나에서 평균 4개, 분산 4개가 계산된다.

이유:

미니배치 안에 샘플이 4개이므로, 각 샘플마다 평균과 분산을 구하기 때문이다.

LayerNorm 직관:

이 샘플 하나의 특성들이 전체적으로 어떤 크기와 분포를 가지는가?

---

## 17. BatchNorm과 LayerNorm 핵심 차이

BatchNorm:

- 미니배치 안의 샘플들을 비교함
- 같은 특성끼리 묶어서 정규화함
- 세로 방향 정규화
- 배치 크기에 영향을 많이 받음
- 학습 시 batch 통계, 추론 시 running 통계를 사용함
- CNN, 이미지 모델에서 자주 사용됨

LayerNorm:

- 다른 샘플을 보지 않음
- 한 샘플 안의 특성들을 묶어서 정규화함
- 가로 방향 정규화
- 배치 크기에 덜 민감함
- 학습과 추론 방식이 거의 같음
- RNN, Transformer, NLP 모델에서 자주 사용됨

짧게 정리:

BatchNorm:
같은 특성의 값을 여러 샘플에서 모아 정규화

LayerNorm:
한 샘플 안의 여러 특성 값을 모아 정규화

## 18. 전체 정리

기울기 소실:

역전파 과정에서 gradient가 점점 작아져 앞쪽 층이 학습되지 않는 문제

기울기 폭주:

gradient가 점점 커져 가중치가 비정상적으로 커지고 학습이 불안정해지는 문제

완화 방법:

1. ReLU / Leaky ReLU 사용
   - sigmoid의 포화 문제를 피함
   - Leaky ReLU는 죽은 ReLU 문제를 완화함

2. 적절한 가중치 초기화
   - tanh, sigmoid 계열이면 Xavier 초기화
   - ReLU 계열이면 He 초기화
   - 목표는 층을 지나도 activation과 gradient의 크기를 적당히 유지하는 것

3. Batch Normalization
   - 미니배치 기준으로 각 특성의 평균과 분산을 구해 정규화
   - 학습 안정화, 더 큰 학습률 사용 가능, 초기화 민감도 감소
   - 배치 크기에 민감함

4. Layer Normalization
   - 각 샘플 안의 특성들을 기준으로 정규화
   - 배치 크기에 덜 민감함
   - RNN, Transformer 계열에서 자주 사용됨

---

## 19. 한 줄 복습

기울기 소실과 폭주는 깊은 신경망에서 gradient가 너무 작아지거나 커지는 문제이고, 이를 완화하기 위해 ReLU 계열 activation, Xavier/He 초기화, BatchNorm, LayerNorm 등을 사용한다.

Xavier는 tanh/sigmoid 계열에, He는 ReLU 계열에 잘 맞는다.

BatchNorm은 미니배치 안에서 특성별로 정규화하고, LayerNorm은 각 샘플 안에서 특성별로 정규화한다.
