# Backpropagation Review Trigger

## 1. 전체 흐름

신경망 학습은 크게 두 단계로 반복된다.

1. 순전파
   - 입력값을 넣고 예측값을 계산한다.
   - 예측값과 실제값의 차이로 loss를 계산한다.

2. 역전파
   - loss가 각 가중치에 얼마나 영향을 받았는지 계산한다.
   - chain rule을 이용해 뒤쪽 가중치부터 앞쪽 가중치까지 기울기를 구한다.
   - 가중치를 loss가 줄어드는 방향으로 조금씩 수정한다.

핵심은 다음이다.

순전파는 값을 만드는 과정이고,
역전파는 그 값들이 loss에 얼마나 책임이 있는지 거꾸로 따지는 과정이다.

## 2. 예제 신경망 구조

예제는 다음 구조를 가진다.

입력층: x1, x2  
은닉층: h1, h2  
출력층: o1, o2  

가중치는 다음과 같이 연결된다.

x1, x2 → h1 : W1, W2  
x1, x2 → h2 : W3, W4  

h1, h2 → o1 : W5, W6  
h1, h2 → o2 : W7, W8  

즉, W1~W4는 입력층에서 은닉층으로 가는 가중치이고,  
W5~W8은 은닉층에서 출력층으로 가는 가중치이다.

## 3. 순전파 감각

순전파는 입력에서 출력 방향으로 계산한다.

먼저 은닉층으로 간다.

z1 = W1*x1 + W2*x2  
h1 = sigmoid(z1)

z2 = W3*x1 + W4*x2  
h2 = sigmoid(z2)

여기서 z는 아직 활성화 함수를 지나기 전의 값이다.

h는 z가 sigmoid를 지난 후의 은닉층 출력값이다.

그다음 출력층으로 간다.

z3 = W5*h1 + W6*h2  
o1 = sigmoid(z3)

z4 = W7*h1 + W8*h2  
o2 = sigmoid(z4)

마지막으로 예측값 o1, o2와 실제값 target을 비교해서 loss를 구한다.

E_total = E_o1 + E_o2

여기까지가 순전파이다.

즉, 순전파는 다음 흐름이다.

x1, x2
→ z1, z2
→ h1, h2
→ z3, z4
→ o1, o2
→ E_total

## 4. 역전파의 핵심 감각

역전파는 출력층에서 입력층 방향으로 진행한다.

즉, 순전파의 반대 방향이다.

순전파:
x → h → o → loss

역전파:
loss → o → h → x 방향의 가중치들

하지만 실제로 x 자체를 바꾸는 것이 아니라,  
각 연결선의 가중치 W를 업데이트한다.

역전파의 질문은 이것이다.

“이 가중치 W가 loss에 얼마나 영향을 주었는가?”

이 값을 구한 것이 기울기이다.

기울기가 크면 해당 가중치가 loss에 큰 영향을 준 것이고,  
기울기가 작으면 해당 가중치가 loss에 적게 영향을 준 것이다.

## 5. Chain Rule이 필요한 이유

W5가 loss에 영향을 주는 경로를 보면 다음과 같다.

W5 → z3 → o1 → E_total

즉, W5가 직접 E_total에 연결된 것이 아니다.

W5는 z3에 영향을 주고,  
z3는 o1에 영향을 주고,  
o1은 E_total에 영향을 준다.

그래서 W5가 E_total에 미치는 영향은 여러 단계의 영향을 곱해서 계산한다.

dE_total/dW5
= dE_total/do1 * do1/dz3 * dz3/dW5

이게 chain rule이다.

즉, chain rule은 “중간 단계들을 거쳐 전달된 영향력”을 계산하는 방법이다.

## 6. 출력층 쪽 가중치 업데이트

먼저 출력층에 가까운 W5, W6, W7, W8부터 업데이트한다.

예를 들어 W5를 보자.

W5는 h1에서 o1으로 가는 가중치이다.

순전파에서 W5는 z3 계산에 사용되었다.

z3 = W5*h1 + W6*h2  
o1 = sigmoid(z3)

따라서 W5를 업데이트하려면 다음을 계산한다.

dE_total/dW5
= dE_total/do1 * do1/dz3 * dz3/dW5

각 항의 의미는 다음과 같다.

dE_total/do1:
o1이 틀렸을 때 loss가 얼마나 변하는가

do1/dz3:
z3가 변하면 sigmoid를 거친 o1이 얼마나 변하는가

dz3/dW5:
W5가 변하면 z3가 얼마나 변하는가

여기서 dz3/dW5 = h1 이다.

왜냐하면 z3 = W5*h1 + W6*h2 이므로,  
W5에 대해 미분하면 h1만 남기 때문이다.

따라서 W5의 기울기는 다음 느낌이다.

W5의 책임
= 출력 o1의 오차 책임
* sigmoid의 변화율
* W5 앞에 있던 입력값 h1

이렇게 구한 기울기로 W5를 업데이트한다.

W5_new = W5 - learning_rate * dE_total/dW5

W6도 같은 방식이다.

dE_total/dW6
= dE_total/do1 * do1/dz3 * dz3/dW6

여기서 dz3/dW6 = h2 이다.

W7, W8은 o2 쪽 출력에 연결되어 있으므로 비슷하게 계산한다.

dE_total/dW7
= dE_total/do2 * do2/dz4 * dz4/dW7

dE_total/dW8
= dE_total/do2 * do2/dz4 * dz4/dW8

정리하면, W5~W8은 출력층과 바로 연결되어 있어서 비교적 직관적이다.

해당 출력값이 얼마나 틀렸는지 보고,  
그 책임을 해당 가중치에 나누어 반영한다.

## 7. 입력층 쪽 가중치 업데이트가 더 헷갈리는 이유

이제 W1, W2, W3, W4를 업데이트해야 한다.

예를 들어 W1을 보자.

W1은 x1에서 h1으로 가는 가중치이다.

문제는 h1이 출력 하나에만 영향을 주는 것이 아니라는 점이다.

h1은 o1에도 영향을 주고,  
h1은 o2에도 영향을 준다.

즉, W1이 loss에 영향을 주는 경로는 하나가 아니다.

W1 → z1 → h1 → z3 → o1 → E_o1  
W1 → z1 → h1 → z4 → o2 → E_o2

따라서 W1의 책임을 계산하려면, h1을 통해 발생한 두 출력의 책임을 모두 합쳐야 한다.

먼저 h1의 전체 책임을 구한다.

dE_total/dh1
= dE_o1/dh1 + dE_o2/dh1

이 말은 다음과 같다.

h1은 o1에도 영향을 줬고,
h1은 o2에도 영향을 줬으므로,
h1의 책임은 두 방향의 책임을 합친 것이다.

그다음 W1에 대한 기울기를 구한다.

dE_total/dW1
= dE_total/dh1 * dh1/dz1 * dz1/dW1

각 항의 의미는 다음과 같다.

dE_total/dh1:
h1이 전체 loss에 얼마나 영향을 주었는가

dh1/dz1:
z1이 변하면 sigmoid를 거친 h1이 얼마나 변하는가

dz1/dW1:
W1이 변하면 z1이 얼마나 변하는가

여기서 dz1/dW1 = x1 이다.

왜냐하면 z1 = W1*x1 + W2*x2 이므로,  
W1에 대해 미분하면 x1만 남기 때문이다.

따라서 W1의 책임은 다음 느낌이다.

W1의 책임
= h1이 전체 loss에 미친 책임
* sigmoid의 변화율
* W1 앞에 있던 입력값 x1

그 후 업데이트한다.

W1_new = W1 - learning_rate * dE_total/dW1

## 8. W2, W3, W4도 같은 방식

W2도 h1으로 들어가는 가중치이므로 W1과 거의 같다.

dE_total/dW2
= dE_total/dh1 * dh1/dz1 * dz1/dW2

여기서 dz1/dW2 = x2 이다.

W3, W4는 h2로 들어가는 가중치이다.

따라서 h2의 책임을 먼저 구해야 한다.

dE_total/dh2
= dE_o1/dh2 + dE_o2/dh2

그 후 W3, W4의 기울기를 구한다.

dE_total/dW3
= dE_total/dh2 * dh2/dz2 * dz2/dW3

dE_total/dW4
= dE_total/dh2 * dh2/dz2 * dz2/dW4

여기서 dz2/dW3 = x1  
여기서 dz2/dW4 = x2

## 9. 역전파를 한 문장으로 이해하기

역전파는 “최종 loss의 책임을 출력층에서 입력층 방향으로 나누어 전달하면서, 각 가중치가 loss에 얼마나 기여했는지 계산하는 과정”이다.

더 짧게 말하면 다음과 같다.

역전파 = chain rule로 각 W의 책임을 계산하는 과정

## 10. 업데이트의 의미

가중치 업데이트 공식은 다음과 같다.

W_new = W_old - learning_rate * dE/dW

여기서 dE/dW는 해당 가중치 방향으로 loss가 얼마나 증가하는지를 의미한다.

따라서 그 방향으로 그대로 가면 loss가 커진다.

그래서 빼준다.

즉, loss가 커지는 방향의 반대로 조금 이동한다.

이것이 경사 하강법이다.

## 11. 순전파와 역전파의 관계

순전파 때 계산한 값들은 역전파 때 다시 사용된다.

예를 들어 W5를 업데이트할 때 h1이 필요하다.

dE_total/dW5
= dE_total/do1 * do1/dz3 * dz3/dW5

여기서 dz3/dW5 = h1 이므로,  
순전파 때 계산한 h1이 역전파에 필요하다.

또 sigmoid 미분도 순전파 결과를 이용한다.

sigmoid 미분 = output * (1 - output)

예를 들어 o1 = sigmoid(z3)이면,

do1/dz3 = o1 * (1 - o1)

따라서 역전파는 순전파와 완전히 분리된 과정이 아니다.

순전파에서 중간값을 계산하고,
역전파에서 그 중간값을 이용해 기울기를 계산한다.

## 12. PyTorch 관점에서 연결하기

PyTorch에서는 우리가 위 미분식을 직접 전부 계산하지 않는다.

대신 다음처럼 한다.

```
prediction = model(x)
loss = criterion(prediction, y)

optimizer.zero_grad()
loss.backward()
optimizer.step()
```

여기서 의미는 다음과 같다.

prediction = model(x):
순전파 수행

loss = criterion(prediction, y):
예측값과 정답의 차이 계산

loss.backward():
chain rule을 이용해 각 파라미터의 기울기 계산

optimizer.step():
계산된 기울기를 이용해 파라미터 업데이트

즉, PyTorch의 backward는 우리가 손으로 계산한 dE/dW들을 자동으로 구해주는 과정이다.

## 13. 가장 중요한 복습 포인트

순전파는 값을 만든다.

x1, x2
→ z1, z2
→ h1, h2
→ z3, z4
→ o1, o2
→ loss

역전파는 책임을 계산한다.

loss
→ o1, o2
→ z3, z4
→ h1, h2
→ z1, z2
→ W1~W8

출력층 가까운 가중치 W5~W8은 출력 오차에서 바로 책임을 계산한다.

입력층 가까운 가중치 W1~W4는 은닉층 h1, h2가 여러 출력에 영향을 주었으므로, 그 책임을 합산해서 계산한다.

chain rule은 중간 변수들을 거쳐 loss까지 이어지는 영향력을 곱해서 계산하는 방법이다.

결국 역전파는 “각 가중치를 얼마나, 어느 방향으로 바꿔야 loss가 줄어드는지”를 알아내는 과정이다.
