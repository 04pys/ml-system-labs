# 06-01 Introduction to Basic Machine Learning Concepts

## 1. 머신러닝 모델의 평가

머신러닝에서는 보통 데이터를 다음처럼 나눈다.

- 훈련 데이터: 모델이 실제로 학습하는 데이터
- 검증 데이터: 하이퍼파라미터 조정, 과적합 여부 확인에 사용하는 데이터
- 테스트 데이터: 최종 성능 평가에 사용하는 데이터

검증 데이터는 최종 평가용이 아니라, 학습 과정에서 모델 설정을 조정하기 위한 데이터다.  
하이퍼파라미터 튜닝이 끝난 뒤에는 아직 모델이 보지 않은 테스트 데이터로 최종 성능을 확인한다.

## 2. 하이퍼파라미터와 매개변수

하이퍼파라미터는 사람이 직접 정하는 값이다.

- learning rate
- epoch 수
- batch size
- 은닉층 수
- 은닉층 뉴런 수
- dropout 비율

반면 매개변수는 모델이 학습하면서 자동으로 업데이트하는 값이다.

- W
- b

정리하면 다음과 같다.

> 하이퍼파라미터 = 사람이 정하는 값  
> 매개변수 = 모델이 학습으로 조정하는 값

## 3. 분류와 회귀

분류는 정해진 선택지 중 하나를 고르는 문제다.

- 이진 분류: 합격/불합격, 스팸/정상
- 다중 클래스 분류: 0~9 숫자 분류, 여러 카테고리 중 하나 선택

회귀는 연속적인 값을 예측하는 문제다.

- 시험 점수 예측
- 주가 예측
- 생산량 예측

로지스틱 회귀는 이름에 “회귀”가 들어가지만, 실제로는 이진 분류에 사용된다.

## 4. 지도 학습과 비지도 학습

지도 학습은 정답 label이 있는 상태에서 학습하는 방식이다.

```
입력 x → 모델 → 예측값 ŷ
정답 y와 비교 → 손실 계산
손실을 줄이도록 W, b 업데이트
```

비지도 학습은 정답 label 없이 데이터의 구조나 패턴을 찾는 방식이다.

예시:

- clustering
- dimensionality reduction

## 5. 샘플과 특성

하나의 데이터 행을 sample이라고 한다.

예를 들어 데이터가 다음과 같다면,

```
[공부시간, 출석률, 과제점수, 중간고사점수]
```

이 한 줄이 하나의 sample이다.

각각의 독립 변수는 feature라고 한다.

```
공부시간 = feature 1
출석률 = feature 2
과제점수 = feature 3
중간고사점수 = feature 4
```

모델은 여러 feature를 이용해 정답 y를 예측한다.

## 6. 혼동 행렬, 정밀도, 재현율

이진 분류에서는 예측 결과를 다음 네 가지로 나눈다.

- TP: 양성이라고 예측했고 실제로도 양성
- TN: 음성이라고 예측했고 실제로도 음성
- FP: 양성이라고 예측했지만 실제로는 음성
- FN: 음성이라고 예측했지만 실제로는 양성

정밀도는 “양성이라고 예측한 것 중 실제 양성의 비율”이다.

```
Precision = TP / (TP + FP)
```

재현율은 “실제 양성 중 양성으로 맞춘 비율”이다.

```
Recall = TP / (TP + FN)
```

정확도만 보면 어떤 종류의 오답이 많은지 알기 어렵기 때문에, 혼동 행렬을 함께 확인한다.

## 7. 과적합과 과소적합

과적합은 모델이 훈련 데이터에 너무 맞춰진 상태다.

```
훈련 데이터 성능은 좋음
테스트 데이터 성능은 나쁨
```

즉, 공부한 문제를 외워서 새로운 문제에는 약한 상태와 비슷하다.

과소적합은 모델이 충분히 학습하지 못한 상태다.

```
훈련 데이터 성능도 낮음
테스트 데이터 성능도 낮음
```

과적합을 줄이는 방법으로는 dropout, early stopping 등이 있다.

## 8. 출력층의 sigmoid, softmax

지금까지 배운 선형 회귀, 로지스틱 회귀, 소프트맥스 회귀는 기본적으로 은닉층이 없는 모델이다.

선형 회귀:

```
x → Wx + b → 예측값
```

로지스틱 회귀:

```
x → Wx + b → sigmoid → 이진 분류 확률
```

소프트맥스 회귀:

```
x → Wx + b → softmax → 다중 클래스 확률분포
```

즉, 입력층에서 바로 출력층으로 간다.  
중간에 은닉층이 없다.

따라서 지금까지 사용한 sigmoid와 softmax는 보통 은닉층 활성화 함수가 아니라, 출력층에서 예측값을 해석 가능한 형태로 바꾸는 함수다.

```
sigmoid: 이진 분류에서 0~1 사이 확률 출력
softmax: 다중 클래스 분류에서 클래스별 확률분포 출력
```

예를 들어 특성 4개로 클래스 3개를 분류하는 softmax 회귀는 다음과 같다.

```
x: 4개 특성
W.shape = (3, 4)
b.shape = (3,)

z = Wx + b
ŷ = softmax(z)
```

구조는 다음과 같다.

```
입력 4개 → 출력 3개
```

역전파는 대략 다음 흐름으로 진행된다.

```
loss → softmax → z = Wx + b → W, b
```

그리고 optimizer.step()을 통해 손실을 줄이는 방향으로 W, b가 업데이트된다.

## 9. 은닉층은 언제 등장하는가

은닉층은 입력을 바로 출력으로 보내지 않고, 중간 표현을 한 번 이상 만든 뒤 출력으로 보내는 층이다.

은닉층이 없는 softmax 회귀:

```
x → Wx + b → softmax → 예측
```

은닉층이 있는 신경망:

```
x → W1x + b1 → ReLU → W2h + b2 → softmax → 예측
```

예를 들어 특성 4개, 클래스 3개 문제에서 은닉층 뉴런을 5개 둔다면 구조는 다음과 같다.

```
입력 4개 → 은닉층 5개 → 출력 3개
```

수식으로는 다음과 같다.

```
h = ReLU(W1x + b1)
z = W2h + b2
ŷ = softmax(z)
```

이때 크기는 대략 다음처럼 된다.

```
W1.shape = (5, 4)
b1.shape = (5,)

W2.shape = (3, 5)
b2.shape = (3,)
```

즉, 은닉층을 쓰면 입력 특성 4개를 바로 클래스 3개로 보내는 것이 아니라, 먼저 5개의 중간 특징 h를 만든 뒤 그 h를 이용해 최종 분류를 한다.

## 10. 은닉층의 정확한 역할

은닉층은 입력 특성을 더 분류하기 좋은 표현으로 바꾸는 역할을 한다.

원래 softmax 회귀는 입력 특성들을 한 번의 선형 조합으로 바로 분류한다.

```
클래스 점수 = w1x1 + w2x2 + w3x3 + w4x4 + b
```

이 방식은 기본적으로 선형적인 판단이다.  
즉, 직선이나 평면으로 데이터를 나누는 데 적합하다.

하지만 실제 데이터는 단순한 직선 하나로 나뉘지 않을 수 있다.  
은닉층은 여러 개의 조건을 만들어서 입력 공간을 더 잘게 나눈다.

예를 들어 은닉 뉴런 하나가 다음과 같다고 하자.

```
h1 = ReLU(2x1 - x2 + 0.5x3 - 3)
```

이 뉴런은 단순히 x1 하나만 보는 것이 아니라 다음 조건을 본다.

```
2x1 - x2 + 0.5x3 - 3 > 0
```

조건을 만족하면 값이 살아나고, 만족하지 않으면 0이 된다.

즉, 은닉 뉴런 하나는 “특정 특성 조합 조건을 만족하는가?”를 확인하는 장치처럼 볼 수 있다.

여러 은닉 뉴런이 있으면 다음처럼 여러 조건을 동시에 만들 수 있다.

```
h1: 어떤 특성 조합 조건
h2: 다른 특성 조합 조건
h3: 또 다른 특성 조합 조건
...
```

출력층은 이 조건들의 결과를 다시 조합해서 최종 클래스를 판단한다.

```
이 조건과 저 조건이 켜지면 class 1
다른 조건이 켜지면 class 2
```

따라서 은닉층은 원래 입력을 다음처럼 바꾼다.

```
원래 입력:
[x1, x2, x3, x4]

은닉층 표현:
[조건1 만족도, 조건2 만족도, 조건3 만족도, ...]
```

## 11. 2차원 예시로 보는 은닉층의 역할

입력 특성이 2개라고 하자.

```
x = [x1, x2]
```

그리고 우리가 찾고 싶은 클래스가 다음 영역에 있다고 하자.

```
0 < x1 < 1
0 < x2 < 1
```

즉, 2차원 평면에서 가운데 사각형 안에 있는 점들만 특정 클래스에 속하는 문제다.

이 문제는 단순 선형 모델 하나로는 잘 나누기 어렵다.  
선형 모델은 기본적으로 직선 하나로 영역을 나누기 때문이다.

그런데 ReLU 은닉층을 쓰면 다음과 같은 조건들을 만들 수 있다.

```
h1 = ReLU(x1)
h2 = ReLU(x2)
h3 = ReLU(x1 - 1)
h4 = ReLU(x2 - 1)
```

각 은닉 뉴런은 다음 의미를 가진다.

```
h1: x1이 0보다 큰 정도
h2: x2가 0보다 큰 정도
h3: x1이 1보다 넘어간 정도
h4: x2가 1보다 넘어간 정도
```

그다음 출력층에서 이 값들을 조합할 수 있다.

```
score = h1 + h2 - 2h3 - 2h4
```

이 식의 직관은 다음과 같다.

```
x1, x2가 0보다 크면 점수 증가
하지만 x1이 1을 넘으면 점수 감소
x2가 1을 넘으면 점수 감소
```

즉, ReLU 뉴런들은 각각 단순한 조건을 만들고, 출력층은 그 조건들을 조합해서 “특정 범위 안에 있는가?” 같은 더 복잡한 판단을 할 수 있다.

이 예시가 중요한 이유는 다음과 같다.

> ReLU 하나는 단순하지만, 여러 ReLU가 각자 경계선을 만들고, 출력층이 그것들을 더하고 빼면 사각형 같은 복잡한 영역도 표현할 수 있다.

그래서 은닉층은 단순히 층을 하나 더 넣는 것이 아니라, 입력 공간을 여러 조각으로 나누고 그 조각들을 다시 조합하는 역할을 한다.

## 12. 비선형 활성화 함수가 필요한 이유

은닉층을 여러 개 쌓더라도 활성화 함수가 선형 함수라면, 전체 모델은 결국 하나의 선형 변환으로 합쳐진다.

```
Linear → Linear → Linear
```

이 구조는 결국 다음과 비슷하다.

```
하나의 Linear
```

그래서 은닉층을 의미 있게 사용하려면 선형 변환 사이에 비선형 활성화 함수가 필요하다.

```
Linear → ReLU → Linear → ReLU → Linear
```

이렇게 해야 모델이 단순 직선/평면이 아니라 더 복잡한 결정 경계를 만들 수 있다.

## 13. sigmoid를 은닉층에서 잘 쓰지 않는 이유

sigmoid 함수는 출력을 0과 1 사이로 만든다.

문제는 입력값이 너무 크거나 작으면 그래프가 거의 평평해진다는 점이다.

```
sigmoid 출력이 0 또는 1에 가까움
→ 기울기가 0에 가까워짐
→ 역전파 때 작은 기울기가 계속 곱해짐
→ 앞쪽 층까지 기울기가 잘 전달되지 않음
```

이것이 기울기 소실 문제다.

따라서 sigmoid는 출력층에서는 사용할 수 있지만, 깊은 신경망의 은닉층에서 반복적으로 사용하는 것은 지양한다.

중요한 구분은 다음과 같다.

```
은닉층의 sigmoid 사용 ≠ 출력층의 sigmoid 사용
```

로지스틱 회귀에서 sigmoid를 사용하는 이유는 은닉층 활성화 함수로 쓰기 위해서가 아니라, 최종 출력을 이진 분류 확률로 바꾸기 위해서다.

```
x → Wx + b → sigmoid → P(y = 1 | x)
```

## 14. tanh는 sigmoid보다 왜 은닉층에서 낫다고 하는가

tanh는 출력을 -1과 1 사이로 만든다.

```
sigmoid: 0 ~ 1
tanh: -1 ~ 1
```

tanh도 입력값의 절댓값이 커지면 -1 또는 1에 가까워지면서 기울기 소실 문제가 생길 수 있다.  
하지만 sigmoid와 달리 0을 중심으로 값이 분포한다.

```
sigmoid는 항상 양수 출력 → 중심이 0이 아님
tanh는 음수와 양수 출력 → 중심이 0에 가까움
```

그래서 tanh는 sigmoid보다 은닉층에서 상대적으로 낫다.  
다만 tanh도 포화 구간에서는 기울기 소실 문제가 있으므로, 최근에는 보통 ReLU 계열을 더 많이 사용한다.

## 15. ReLU와 Leaky ReLU

ReLU는 다음과 같다.

```
ReLU(x) = max(0, x)
```

즉,

```
x가 음수면 0
x가 양수면 x 그대로
```

ReLU의 장점은 다음과 같다.

- 양수 구간에서 기울기가 1이라 기울기 전달이 비교적 잘 됨
- 계산이 단순하고 빠름
- 깊은 신경망에서 sigmoid보다 잘 작동하는 경우가 많음

단점은 다음과 같다.

- 음수 구간에서는 기울기가 0
- 어떤 뉴런이 계속 음수만 받으면 학습이 멈출 수 있음
- 이를 dying ReLU 문제라고 함

Leaky ReLU는 음수 구간에서도 아주 작은 기울기를 남긴다.

```
Leaky ReLU(x) = x       if x > 0
Leaky ReLU(x) = ax      if x <= 0
```

그래서 ReLU처럼 뉴런이 완전히 죽어버리는 문제를 줄일 수 있다.

## 16. 전체 복습 핵심

선형 회귀, 로지스틱 회귀, 소프트맥스 회귀는 기본적으로 은닉층 없이 입력에서 출력으로 바로 가는 모델이다.

```
x → Wx + b → output
```

이때 sigmoid와 softmax는 출력층에서 예측값을 해석 가능한 형태로 바꾸는 역할을 한다.

```
sigmoid: 이진 분류 확률
softmax: 다중 클래스 확률분포
```

반면 은닉층이 있는 신경망은 입력을 바로 출력으로 보내지 않고, 중간 표현을 만든다.

```
x → W1x + b1 → ReLU → W2h + b2 → output
```

은닉층의 핵심 역할은 다음과 같다.

```
1. 입력 특성들을 여러 방식으로 선형 조합한다.
2. ReLU 같은 활성화 함수로 조건을 켜고 끈다.
3. 그 조건들을 출력층에서 다시 조합한다.
4. 결과적으로 단순 선형 모델보다 복잡한 결정 경계를 표현한다.
```
