# LSTM과 GRU

## 1. 왜 LSTM과 GRU가 필요한가?

바닐라 RNN은 현재 입력 x_t와 이전 은닉 상태 h_(t-1)을 이용해 현재 은닉 상태 h_t를 만든다.

RNN 기본 구조:

h_t = tanh(W_x x_t + W_h h_(t-1) + b)

이 구조는 짧은 시퀀스에서는 잘 작동하지만, time step이 길어질수록 앞쪽 정보가 뒤쪽까지 충분히 전달되지 못하는 문제가 있다.

예를 들어 문장 앞부분에 나온 "모스크바"라는 장소 정보가 문장 뒤쪽의 빈칸 예측에 필요할 수 있다. 하지만 바닐라 RNN은 시간이 많이 지나면 앞쪽 정보를 거의 잃어버릴 수 있다.

이 문제를 장기 의존성 문제라고 한다.

LSTM과 GRU는 이 장기 의존성 문제를 완화하기 위해 나온 RNN의 변형 구조이다.

---

## 2. LSTM의 핵심 아이디어

LSTM은 RNN이 h_t 하나에 기억과 출력을 모두 담던 문제를 보완한다.

LSTM은 상태를 두 개로 나눈다.

C_t = 셀 상태, 장기 기억

h_t = 은닉 상태, 단기 상태, 현재 출력용 상태

즉, LSTM은 기억을 저장하는 공간 C_t와 현재 시점에서 밖으로 드러나는 상태 h_t를 분리한다.

비유하면 다음과 같다.

C_t = 계속 유지되는 노트 전체

h_t = 지금 필요한 부분만 꺼낸 요약 메모

그래서 LSTM은 매 시점마다 다음을 결정한다.

1. 이전 기억 중 무엇을 버릴지
2. 현재 입력에서 무엇을 새로 기억할지
3. 업데이트된 장기 기억 중 무엇을 현재 출력으로 보여줄지

이를 위해 LSTM은 세 개의 게이트를 사용한다.

입력 게이트 i_t

삭제 게이트 또는 망각 게이트 f_t

출력 게이트 o_t

---

## 3. LSTM의 입력값과 출력값

한 시점 t에서 LSTM은 다음 값을 받는다.

x_t = 현재 시점의 입력

h_(t-1) = 이전 시점의 은닉 상태

C_(t-1) = 이전 시점의 셀 상태, 장기 기억

그리고 다음 값을 만든다.

C_t = 현재 시점의 셀 상태, 업데이트된 장기 기억

h_t = 현재 시점의 은닉 상태, 단기 상태, 출력용 상태

---

## 4. LSTM의 입력 게이트

입력 게이트는 현재 입력에서 새롭게 기억할 정보를 결정한다.

i_t = sigmoid(W_xi x_t + W_hi h_(t-1) + b_i)

g_t = tanh(W_xg x_t + W_hg h_(t-1) + b_g)

여기서 i_t와 g_t는 역할이 다르다.

i_t = 새 후보 기억을 얼마나 반영할지 정하는 게이트

g_t = 현재 입력과 이전 은닉 상태를 바탕으로 만든 새 기억 후보

sigmoid를 통과한 i_t는 0과 1 사이 값이다.

i_t가 0에 가까우면 새 후보 기억을 거의 반영하지 않는다.

i_t가 1에 가까우면 새 후보 기억을 많이 반영한다.

tanh를 통과한 g_t는 -1과 1 사이 값이다.

즉, g_t는 실제로 새로 기억할 만한 내용이고, i_t는 그 내용을 얼마나 쓸지 정하는 문지기이다.

---

## 5. LSTM의 삭제 게이트, 망각 게이트

삭제 게이트는 이전 장기 기억 C_(t-1)을 얼마나 보존할지 결정한다.

f_t = sigmoid(W_xf x_t + W_hf h_(t-1) + b_f)

f_t는 0과 1 사이 값이다.

f_t가 0에 가까우면 이전 기억을 거의 버린다.

f_t가 1에 가까우면 이전 기억을 거의 그대로 유지한다.

즉, f_t는 C_(t-1)에 대해 "얼마나 남길까?"를 정하는 게이트이다.

---

## 6. LSTM의 셀 상태 C_t

LSTM에서 가장 중요한 식은 셀 상태 업데이트이다.

C_t = f_t * C_(t-1) + i_t * g_t

여기서 *는 같은 위치의 성분끼리 곱하는 원소별 곱이다.

이 식은 다음처럼 이해하면 된다.

f_t * C_(t-1) = 이전 기억 중 남길 부분

i_t * g_t = 현재 입력에서 새롭게 추가할 기억

따라서 전체 의미는 다음과 같다.

C_t = 이전 기억 중 남길 것 + 현재 입력에서 새로 쓸 것

즉, C_t는 LSTM의 장기 기억이다.

중요한 점은 삭제 게이트 f_t와 입력 게이트 i_t가 서로 독립적이라는 것이다.

이론적으로 LSTM은 이전 기억도 많이 남기면서 새 기억도 많이 추가할 수 있다.

또는 이전 기억을 거의 버리고 새 기억 중심으로 바꿀 수도 있다.

---

## 7. LSTM의 출력 게이트와 은닉 상태 h_t

출력 게이트는 장기 기억 C_t 중에서 현재 시점에 밖으로 보여줄 부분을 결정한다.

o_t = sigmoid(W_xo x_t + W_ho h_(t-1) + b_o)

h_t = o_t * tanh(C_t)

주의할 점은 o_t가 단기 상태 자체가 아니라는 것이다.

o_t = 현재 장기 기억 중 얼마를 드러낼지 정하는 출력 게이트

h_t = 실제 단기 상태, 현재 출력용 상태

C_t는 장기 기억이다. 하지만 장기 기억 전체를 매 시점마다 그대로 출력할 필요는 없다.

그래서 LSTM은 먼저 C_t를 tanh에 넣어 -1과 1 사이로 정리한다.

tanh(C_t) = 출력하기 좋은 형태로 정리된 장기 기억

그다음 o_t와 원소별 곱을 한다.

o_t * tanh(C_t) = 현재 시점에 실제로 보여줄 기억

즉, h_t는 C_t 전체가 아니라, C_t 중 현재 시점에서 필요한 부분만 꺼낸 결과이다.

비유하면 다음과 같다.

C_t = 노트 전체

tanh(C_t) = 정리된 노트 내용

o_t = 지금 발표할 내용에 붙이는 형광펜

h_t = 형광펜이 칠해진 부분만 꺼낸 발표용 메모

---

## 8. LSTM을 한 번에 정리하기

LSTM은 매 시점마다 다음 순서로 작동한다.

1. 현재 입력 x_t와 이전 은닉 상태 h_(t-1)을 본다.

2. f_t로 이전 장기 기억 C_(t-1)을 얼마나 남길지 정한다.

3. i_t와 g_t로 현재 입력에서 어떤 정보를 얼마나 새로 기억할지 정한다.

4. C_t = f_t * C_(t-1) + i_t * g_t로 장기 기억을 업데이트한다.

5. o_t로 C_t 중 현재 밖으로 보여줄 부분을 정한다.

6. h_t = o_t * tanh(C_t)로 현재 은닉 상태를 만든다.

핵심 문장:

LSTM은 기억을 저장하는 C_t와 현재 출력으로 쓰는 h_t를 분리하고, 세 개의 게이트로 무엇을 잊고, 무엇을 기억하고, 무엇을 보여줄지 조절하는 RNN 구조이다.

---

## 9. GRU의 핵심 아이디어

GRU는 LSTM을 더 단순하게 만든 구조이다.

LSTM은 C_t와 h_t를 따로 둔다.

GRU는 C_t를 따로 두지 않고 h_t 하나만 사용한다.

즉, GRU에서 h_t는 기억이면서 동시에 출력 상태이다.

LSTM:

C_t = 장기 기억

h_t = 단기 상태, 출력 상태

GRU:

h_t = 기억 + 출력 상태

그래서 GRU는 LSTM보다 구조가 단순하고, 게이트 수도 적다.

LSTM은 게이트가 3개이다.

입력 게이트

삭제 게이트

출력 게이트

GRU는 게이트가 2개이다.

업데이트 게이트 z_t

리셋 게이트 r_t

---

## 10. GRU의 리셋 게이트 r_t

리셋 게이트는 새 후보 기억을 만들 때 과거 정보를 얼마나 참고할지 결정한다.

r_t = sigmoid(W_xr x_t + W_hr h_(t-1) + b_r)

새 후보 기억은 다음과 같이 만든다.

g_t = tanh(W_hg (r_t * h_(t-1)) + W_xg x_t + b_g)

여기서 핵심은 r_t * h_(t-1)이다.

r_t가 0에 가까우면 이전 은닉 상태 h_(t-1)을 거의 무시하고 현재 입력 x_t 중심으로 새 후보 기억을 만든다.

r_t가 1에 가까우면 이전 은닉 상태 h_(t-1)을 많이 참고해서 새 후보 기억을 만든다.

즉, r_t는 "새 기억 후보를 만들 때 과거 맥락을 얼마나 끌고 올까?"를 정하는 게이트이다.

---

## 11. GRU의 업데이트 게이트 z_t

업데이트 게이트는 이전 기억을 유지할지, 새 후보 기억으로 바꿀지의 비율을 정한다.

z_t = sigmoid(W_xz x_t + W_hz h_(t-1) + b_z)

최종 은닉 상태는 다음과 같이 계산한다.

h_t = (1 - z_t) * g_t + z_t * h_(t-1)

이 식이 GRU의 핵심이다.

z_t * h_(t-1) = 이전 기억 중 유지할 부분

(1 - z_t) * g_t = 새 후보 기억 중 반영할 부분

따라서 전체 의미는 다음과 같다.

h_t = 이전 기억 중 남길 것 + 새 후보 기억 중 반영할 것

z_t가 1에 가까우면 h_t는 거의 h_(t-1)이 된다.

즉, 이전 기억을 많이 유지한다.

z_t가 0에 가까우면 h_t는 거의 g_t가 된다.

즉, 새 후보 기억으로 많이 업데이트한다.

---

## 12. GRU와 LSTM의 핵심 비교

| 구분 | LSTM | GRU |
|---|---|---|
| 상태 | C_t와 h_t를 따로 둠 | h_t 하나만 사용 |
| 장기 기억 | C_t가 담당 | h_t가 함께 담당 |
| 출력 상태 | h_t가 담당 | h_t가 담당 |
| 게이트 수 | 3개 | 2개 |
| 게이트 종류 | 입력 게이트, 삭제 게이트, 출력 게이트 | 업데이트 게이트, 리셋 게이트 |
| 출력 게이트 | 있음 | 없음 |
| 구조 | 더 정교함 | 더 단순함 |
| 계산량 | 상대적으로 많음 | 상대적으로 적음 |
| 학습 속도 | 상대적으로 느릴 수 있음 | 상대적으로 빠른 편 |
| 성능 | 많은 데이터와 복잡한 문제에서 강할 수 있음 | LSTM과 비슷한 성능을 보이는 경우가 많음 |

---

## 13. LSTM의 f_t, i_t와 GRU의 z_t 비교

LSTM의 셀 상태 업데이트:

C_t = f_t * C_(t-1) + i_t * g_t

GRU의 은닉 상태 업데이트:

h_t = z_t * h_(t-1) + (1 - z_t) * g_t

둘은 구조가 비슷하다.

공통점:

이전 기억을 얼마나 남길지 정한다.

새 기억을 얼마나 반영할지 정한다.

차이점:

LSTM은 f_t와 i_t가 따로 있다.

GRU는 z_t 하나로 이전 기억과 새 기억의 비율을 함께 조절한다.

LSTM에서는 이전 기억을 많이 남기면서 새 기억도 많이 추가하는 것이 가능하다.

GRU에서는 z_t가 커지면 이전 기억 유지가 커지고, 새 기억 반영은 줄어든다.

즉, GRU는 더 단순하지만 LSTM보다 조절 방식이 덜 독립적이다.

---

## 14. 왜 GRU에는 출력 게이트가 없는가?

LSTM에는 C_t와 h_t가 따로 있다.

C_t는 장기 기억이고, h_t는 현재 출력용 상태이다.

그래서 LSTM은 장기 기억 C_t 중에서 현재 밖으로 보여줄 부분을 고르기 위해 출력 게이트 o_t가 필요하다.

h_t = o_t * tanh(C_t)

하지만 GRU에는 C_t가 없다.

GRU에서는 h_t 하나가 기억이면서 동시에 출력이다.

따라서 "C_t 중 일부를 h_t로 꺼낸다"는 과정이 필요 없다.

그래서 GRU에는 출력 게이트가 없다.

핵심 문장:

LSTM은 기억 저장소 C_t와 출력 상태 h_t가 분리되어 있어서 출력 게이트가 필요하고, GRU는 h_t 하나로 기억과 출력을 모두 처리하기 때문에 출력 게이트가 없다.

---

## 15. LSTM과 GRU를 언제 구분해서 이해하면 좋은가?

LSTM은 다음처럼 이해하면 좋다.

기억 저장소 C_t를 따로 두고, 입력 게이트, 삭제 게이트, 출력 게이트로 기억을 정교하게 관리하는 구조

GRU는 다음처럼 이해하면 좋다.

C_t 없이 h_t 하나만 두고, 업데이트 게이트와 리셋 게이트로 이전 기억과 새 기억을 간단하게 섞는 구조

둘 중 어느 것이 항상 더 좋다고 단정할 수는 없다.

일반적으로 GRU는 구조가 단순해서 계산량이 적고 학습이 빠른 편이다.

LSTM은 구조가 더 정교하고, 데이터가 많거나 복잡한 장기 의존성이 필요한 문제에서 강점을 보일 수 있다.

하지만 실제 성능은 데이터, 모델 크기, 하이퍼파라미터, task에 따라 달라진다.

---

## 16. PyTorch에서의 사용

RNN:

nn.RNN(input_dim, hidden_size, batch_first=True)

LSTM:

nn.LSTM(input_dim, hidden_size, batch_first=True)

GRU:

nn.GRU(input_dim, hidden_size, batch_first=True)

사용 형태는 비슷하지만 내부 구조가 다르다.

RNN은 h_t 하나를 단순히 반복 업데이트한다.

LSTM은 C_t와 h_t를 함께 관리한다.

GRU는 h_t 하나만 관리하되, 업데이트 게이트와 리셋 게이트를 사용한다.

---

## 17. 최종 복습 문장

바닐라 RNN은 긴 시퀀스에서 앞쪽 정보가 뒤로 갈수록 약해지는 장기 의존성 문제가 있다.

LSTM은 이 문제를 해결하기 위해 C_t라는 장기 기억을 추가하고, 입력 게이트, 삭제 게이트, 출력 게이트로 기억의 저장과 노출을 조절한다.

GRU는 LSTM의 핵심 아이디어를 유지하되 C_t를 없애고 h_t 하나만 사용하며, 업데이트 게이트와 리셋 게이트로 더 단순하게 기억을 조절한다.

한 줄 요약:

LSTM = C_t와 h_t를 나누고 3개 게이트로 정교하게 기억 관리

GRU = h_t 하나만 두고 2개 게이트로 간단하게 기억 관리
