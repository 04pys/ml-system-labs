# 05-02 소프트맥스 회귀 복습 정리

## 1. 소프트맥스 회귀가 풀려는 문제

소프트맥스 회귀는 **3개 이상의 선택지 중 1개를 고르는 다중 클래스 분류**에 쓰는 모델이다. 위키독스 예시에서는 붓꽃의 4개 특성으로 3개 품종 중 하나를 맞힌다.

- 입력 예: 꽃받침 길이, 꽃받침 넓이, 꽃잎 길이, 꽃잎 넓이
- 출력 예: setosa / versicolor / virginica 중 하나

---

## 2. 제일 중요한 구분: 입력 차원과 출력 차원은 다를 수 있음

헷갈리기 쉬운 핵심:

- 입력 차원 = 특성 개수
- 출력 차원 = 클래스 개수

붓꽃 예시에서는

- 입력 `x`는 4차원
- 출력은 3개 클래스에 대한 확률 벡터이므로 3차원

즉, **입력을 3차원으로 바꾸는 것이 아니라**,  
4차원 입력을 받아서 모델이 **3차원 점수 벡터**를 새로 만들어내는 것이다. 이 장에서는 입력 `X`, 가중치 `W`, 편향 `B`, 출력 `Ŷ`를 벡터 또는 행렬로 둔다고 설명한다.

---

## 3. 가설식의 의미

로지스틱 회귀는

`H(X) = sigmoid(WX + B)`

소프트맥스 회귀는

`H(X) = softmax(WX + B)`

로 쓴다. 즉, 먼저 `WX + B`로 클래스별 점수를 만들고, 그 점수들을 softmax에 통과시켜 **각 클래스일 확률**로 바꾼다.

복습 포인트:

- `WX + B` 또는 `XW + b`의 결과는 **확률 전 점수(score)** 임
- softmax를 통과한 뒤에야 **확률 벡터**가 됨

---

## 4. p, y, yhat 정리

이 부분이 가장 자주 헷갈림.

- `y`: 정답
- `p`: 모델이 예측한 각 클래스의 확률
- `ŷ` 또는 `yhat`: 예측 결과 전체를 가리키는 표기로 쓰일 수 있음

### 더 정확히
- `y`는 보통 **원-핫 벡터**
- `p_j`는 **j번째 클래스일 확률**
- `y_j`는 정답 클래스면 1, 아니면 0

예를 들어 정답이 2번 클래스면

`y = [0, 1, 0]`

모델 예측이

`p = [0.2, 0.7, 0.1]`

이면, 모델은 2번 클래스를 가장 유력하게 본 것이다.

---

## 5. softmax가 하는 일

softmax는 **점수 벡터를 확률 벡터로 바꾸는 함수**이다. 소프트맥스 회귀는 선택지 개수만큼의 차원을 가지는 벡터를 만든 뒤, 그 벡터의 원소 합이 1이 되도록 변환한다.

예:

- softmax 전 점수: `[2.0, 1.0, 0.1]`
- softmax 후 확률: `[클래스1일 확률, 클래스2일 확률, 클래스3일 확률]`
- 이 확률들의 합은 1

즉 softmax는  
**“이 샘플이 각 클래스일 가능성을 확률 형태로 보여주는 함수”**라고 기억하면 됨

---

## 6. 데이터셋 차원 감각

예를 들어

- 입력 데이터셋 `X`: `5 x 4`
- 정답 데이터셋 `Y`: `5 x 3`

이라면

- 샘플 5개
- 각 샘플 특성 4개
- 클래스 3개

보통

- `W`: `4 x 3`
- `b`: `1 x 3`

이므로

`XW + b`

의 결과는 `5 x 3`이 된다.

즉 각 샘플마다 클래스 3개에 대한 점수 3개가 생긴다.

중요:

- `b`는 샘플마다 따로 두는 것이 아니라, **클래스별로 하나씩만 둠**
- 그래서 `b`는 `5 x 3`이 아니라 `1 x 3`

---

## 7. 한 샘플이 지나가는 흐름

샘플 하나의 입력이

`x = [x1, x2, x3, x4]`

라면 흐름은

`x`
→ `선형변환`
→ `z = [z1, z2, z3]`
→ `softmax(z)`
→ `p = [p1, p2, p3]`

이다.

즉

- 입력은 4개 특성
- 중간에 3개 클래스에 대한 점수 생성
- 마지막에 3개 확률 생성

---

## 8. 손실함수의 의미

크로스 엔트로피 손실은 보통 다음처럼 쓴다.

```
cost(W) = - Σ y_j log(p_j)
```

여기서

- `y_j`: 정답 벡터의 j번째 값
- `p_j`: 모델이 예측한 j번째 클래스의 확률

이다.

소프트맥스 회귀에서는 정답을 보통 **원-핫 벡터**로 표현하므로,  
정답 클래스만 1이고 나머지는 전부 0이다.

예를 들어 정답이 2번 클래스라면

```
y = [0, 1, 0]
```

이다.

그러면 손실함수는

```
-(0*log(p1) + 1*log(p2) + 0*log(p3))
```

가 되고, 결국

```
-log(p2)
```

만 남는다.

즉, 크로스 엔트로피는 겉보기에는 복잡해 보여도,  
원-핫 정답일 때는 사실상

**"정답 클래스에 부여한 확률이 얼마나 큰가"**

만 보는 함수라고 이해하면 된다.

---

## 9. 왜 이런 모양의 손실함수를 쓰는가

핵심 직관은 단순하다.

- 정답 클래스 확률을 높게 주면 손실이 작아짐
- 정답 클래스 확률을 낮게 주면 손실이 커짐
- 특히 틀린 답에 큰 확신을 가질수록 손실이 매우 커짐

즉 이 손실함수는 모델에게

**"정답 클래스의 확률을 최대한 크게 만들어라"**

라고 요구하는 역할을 한다.

또 `log`가 들어가 있기 때문에,  
정답 확률이 조금 낮은 정도는 어느 정도 벌주지만,  
정답 확률이 아주 낮은 경우는 훨씬 더 강하게 벌준다.

---

## 10. 간단한 예시

정답이 2번 클래스라고 하자.

```
y = [0, 1, 0]
```

### 경우 1. 잘 예측한 경우

모델 예측:

```
p = [0.1, 0.8, 0.1]
```

이때 손실은

```
loss = -log(0.8)
```

이므로 작다.

즉, 정답인 2번 클래스에 0.8이라는 높은 확률을 줬기 때문에  
"꽤 잘했다"라고 판단하는 것이다.

### 경우 2. 잘못 예측한 경우

모델 예측:

```
p = [0.7, 0.2, 0.1]
```

이때 손실은

```
loss = -log(0.2)
```

이므로 더 크다.

정답은 2번 클래스인데,  
모델은 1번 클래스 쪽에 더 큰 확률을 줬기 때문이다.

### 경우 3. 확신을 갖고 크게 틀린 경우

모델 예측:

```
p = [0.99, 0.01, 0.0]
```

이때 손실은 사실상

```
loss = -log(0.01)
```

수준이 되어 매우 커진다.

즉, 정답 클래스 확률을 거의 0에 가깝게 주면  
손실함수가 강하게 벌점을 준다.

---

## 11. 손실함수 복습 트리거

- `p`는 예측 확률 벡터
- `y`는 정답 원-핫 벡터
- 크로스 엔트로피는 원-핫 정답일 때 사실상 `-log(정답 클래스 확률)`
- 정답 클래스 확률이 클수록 손실 작음
- 정답 클래스 확률이 작을수록 손실 큼
- 확신하고 틀릴수록 더 크게 벌받음

---

## 12. 구현 들어가기 전 꼭 잡아둘 한 줄들

### 복습 트리거 1
로지스틱 회귀는 **이진 분류**, 소프트맥스 회귀는 **다중 클래스 분류**

### 복습 트리거 2
입력 차원과 출력 차원은 같을 필요 없음  
입력 4차원 → 출력 3차원 가능

### 복습 트리거 3
`WX + B` 또는 `XW + b`의 결과는 **확률이 아니라 점수**

### 복습 트리거 4
softmax는 점수를 **합이 1인 확률 벡터**로 바꾸는 함수

### 복습 트리거 5
`y`는 정답 원-핫 벡터, `p`는 예측 확률 벡터

### 복습 트리거 6
크로스 엔트로피는 결국  
**정답 클래스 확률에 대한 벌점 함수**

### 복습 트리거 7
원-핫일 때 손실함수는 사실상  
`-log(정답 클래스 확률)`

---

## 13. 구현 직전 최종 압축

소프트맥스 회귀는

- 입력 특성들로부터
- 각 클래스의 점수를 만들고
- softmax로 확률로 바꾸고
- 정답 클래스 확률이 커지도록 학습하는 모델

이라고 기억하면 됨

즉 구현 파트에 들어가기 전 머릿속 최소 구조는 이것만 있으면 됨:

`입력 X -> 선형변환 -> 클래스별 점수 -> softmax -> 확률 -> cross entropy -> 업데이트`
